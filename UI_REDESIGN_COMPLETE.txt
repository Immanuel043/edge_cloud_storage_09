┌──────────────────────────────────────────────────────────────────────────┐
│ BACKEND REQUIREMENTS                                                     │
└──────────────────────────────────────────────────────────────────────────┘

TO ENABLE FULL FUNCTIONALITY, IMPLEMENT:

1️⃣  RECENTS API:
   Endpoint: GET /api/files/recents?days=30
   Action:   Query files WHERE last_accessed within days
   Returns:  Array of file objects
   Status:   ⚠️  Using mock data

2️⃣  FAVORITES API:
   Endpoint: GET /api/files/favorites
   Action:   Query favorited files for user
   Returns:  Array of file objects
   Status:   ⚠️  Returns empty array

   Endpoint: POST /api/files/{id}/favorite
   Action:   Toggle favorite status
   Returns:  {favorited: boolean}
   Status:   ⚠️  Frontend only

3️⃣  DATABASE SCHEMA UPDATES:
   ALTER TABLE files ADD COLUMN last_accessed TIMESTAMP;
   
   -- Option A: Add column
   ALTER TABLE files ADD COLUMN favorited BOOLEAN DEFAULT FALSE;
   
   -- Option B: Create table (recommended)
   CREATE TABLE favorites (
       user_id INT REFERENCES users(id),
       file_id INT REFERENCES files(id),
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
       PRIMARY KEY (user_id, file_id)
   );
